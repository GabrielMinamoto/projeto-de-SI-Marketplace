# projeto-de-SI-Marketplace
O projeto Digibuybr desenvolve um marketplace para gestão de anunciantes e logística via consultoria da SupersolucoesTI com foco em escalabilidade.
O objetivo central é entregar um sistema documentado que garanta a plena autonomia da equipe interna para futura manutenção e suporte técnico.
A metodologia ágil orienta a definição de requisitos funcionais e não funcionais, assegurando a validação de processos e o cumprimento do prazo.
Priorizamos a engenharia de software de alta fidelidade para permitir testes de aceitação precisos e a evolução contínua da plataforma de vendas.
O repositório centraliza o levantamento técnico que sustenta as operações comerciais e o planejamento logístico com entrega prevista para novembro.
